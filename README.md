# Autoaprendizaje digital — CLENA

Aplicación web de autoaprendizaje para fortalecer las habilidades digitales de las personas adultas mayores.

## 📚 Acerca del proyecto

La plataforma ofrece guías en formato PDF, lecciones breves con retroalimentación y la posibilidad de solicitar ayuda al personal.

### Problema que aborda

Muchas personas adultas mayores enfrentan dificultades al utilizar Internet. Este proyecto busca ayudarles a:

- Buscar información en línea.
- Evaluar la confiabilidad de los contenidos que encuentran.
- Reconocer prácticas que pueden poner en riesgo su información personal.

Así, promovemos un uso de Internet más autónomo, responsable y seguro.

## 🚀 Cómo iniciar el proyecto

Necesitas tener [Git](https://git-scm.com/) y [Docker Compose](https://docs.docker.com/compose/) instalados.

```bash
git clone https://github.com/MarcusRambal/Autoaprendizaje-digital---Clena.git
cd Autoaprendizaje-digital---Clena
docker compose up
```

Cuando los servicios estén listos, abre el frontend en [http://localhost](http://localhost).

Para detener los servicios, pulsa `Ctrl+C` y ejecuta:

```bash
docker compose down
```
